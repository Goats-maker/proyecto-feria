# Mi Pupusería

## 1. Nombre y la frase de mi ficha

Mi Pupusería

Es un juego donde tengo que administrar mi propia pupusería durante 10 días, comprar los ingredientes, elegir los precios y tratar de ganar dinero sin quedarme en bancarrota.

## 2. Qué hace y cómo se usa, en tres líneas

Mi Pupusería simula administrar una pupusería durante 10 días.
Debes comprar ingredientes, elegir el precio y revisar el clima para ganar dinero y evitar la bancarrota.
Se juega desde el navegador con teclado o botones, día a día, hasta decidir si logras la meta.

## 3. El enlace para abrirlo

[Mi Pupusería](https://goats-maker.github.io/proyecto-feria/)

## 4. Cómo correrlo en otra máquina: los comandos exactos

```bash
git clone https://github.com/Goats-maker/proyecto-feria.git
cd proyecto-feria
npm install
npm run dev -- --host 0.0.0.0
```

Luego abre la URL que te muestre Vite, normalmente `http://localhost:5173`.
